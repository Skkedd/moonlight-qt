# Cortex ARM64 compatibility build, November 12, 2026

Cortex's Visual Studio Build Tools installer added the MSVC 2022 ARM64 C++ component successfully. The build used MSVC 19.44.35229 for ARM64, Windows SDK 10.0.26100.0, the pinned v20.1 ARM64 dependencies, and Qt 6.10.3 x64 host tools with matching ARM64 libraries. The upstream workflow specifies Qt 6.12.0. The checked public Qt package metadata paths for that version returned HTTP 404.

Build source was `617ea82e3a413d320fcf7a7e70c48466859f6dce`. The Windows manifest path needed quoting because the Workshop checkout path contains spaces. The isolated Qt kit required a host qmake/qtpaths wrapper pointed at its sibling x64 tools and the ARM64 target configuration. This compatibility build used qmake with `CONFIG+=release no_batch`, `QT_ARCH=arm64`, and MSVC `/Z7` to embed debug data in objects after the separate PDB writer stalled. It was built with NMAKE.

The unsigned portable package was assembled with Qt's deployment tool, the pinned ARM64 dependency DLLs, and the ARM64 MSVC runtime. The deployment tool initially copied a host x64 ICU DLL. The final package relies on the Windows ICU runtime and contains 88 executables and DLLs, each verified as PE machine `AA64`.
